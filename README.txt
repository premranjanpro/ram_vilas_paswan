रामविलास पासवान डिजिटल बुकलेट

1. index.html को Chrome/Edge में खोलें।
2. Next/Previous से 10 पृष्ठ देखें।
3. PDF डाउनलोड बटन सभी पृष्ठों की PDF बनाएगा।
4. पहली बार PDF हेतु इंटरनेट आवश्यक है क्योंकि html2pdf.js CDN से लोड होता है।
5. ऑफलाइन स्थिति में Print > Save as PDF उपयोग करें।
6. फोटो बदलने के लिए assets/ram-vilas-paswan.jpg को उसी नाम की नई फोटो से replace करें।
7. प्रकाशन से पहले तथ्य, चित्र-अधिकार, वर्तनी और उद्धरण की संपादकीय जाँच करें।
